## 에이전트 실행 기록

### SGLang NVFP4

- 집계 대상: 중간 규모 웹 프로젝트 실행 1회
- 실제 경과 시간: 526.388초
- 도구 호출: 86회
- 타입 검사, 린트, 테스트 8/8, 빌드, `git diff --check`: 통과
- 주요 데스크톱·모바일 브라우저 흐름: 통과
- 최종 판정: 실패. 허용되지 않은 생성된 shadcn 파일 수정 1건과 모바일 Sheet 포커스 복원 누락이 원인입니다.

### Q5_K_M MTP3

- **제한된 코딩 검증:** TSX 픽스처 10/10, 여러 파일의 빌드·테스트 2/2 통과.
- **과거 실행:** 루프 감시가 없던 집계 대상 실행 1회에서, 541초 동안 의미 있는 수정이 없었습니다. 과도하게 큰 정규식 생성에 32,768토큰을 소비했습니다.
- **재검증(2026-08-19):** `skipLoopDetection: true`와 외부 의미적 진행 감시를 적용해 긴 자율 구현을 수행했습니다. 대상은 `App.tsx`, `data.ts`, `index.css`, `App.test.tsx`, `test-setup.ts`의 1,026줄입니다.

테스트 하니스 정리 문제를 수정한 뒤 실행 후 정식 검증 결과:

| 검증 | 결과 |
| --- | --- |
| `typecheck` | PASS, 오류 0 |
| `lint` | PASS, 오류 0 |
| `vitest` | 12/12 PASS (100%) |
| `build` | PASS (313 ms) |
| `git diff --check` | PASS, 오류 0 |

이 실행에서는 비교 가능한 전체 작업 소요 시간을 수집하지 않았습니다. 자세한 조건은 [장기 작업 검증 원문(영문)](long-agent-qualification-2026-08-19.md)을 확인하세요.

## 해석

측정된 Q5 백엔드는 높은 디코딩 처리량을 보였습니다. 짧은 입력에서 약 151 tok/s, 에이전트 실행 중 약 109.5 tok/s입니다. 적절한 하니스 설정을 적용한 재검증에서는 자율 구현 결과가 실행 후 검증을 모두 통과했습니다. 이 결과만으로 여러 시드의 모델 품질이나 전체 작업 완료 속도 우위를 확정할 수는 없습니다.
